## 6. 四类异常专项判断

### 规格 conflict

46 条规格 conflict 均未发现 Python 正式值明显错误。主要原因是 shadow 规格候选按源单元格数字顺序直接比较，而 Gate 2D 正式值使用被套业务方向归一；其中带 `+Xcm` 的记录还需要同一产品行描述中的 flap/overlap/opening 证据，当前规格 source cells 多数只包含尺寸列。

### 款式 dictionary_no_match

42 条款式无匹配不等于 Python 款式错误。多数源文本存在 bag/opening/hand hole/flap/flange 等款式证据，但 shadow 组件提取未覆盖 typo、英文别名或组合表达；另有部分记录已抽取到手洞/飞边等局部组件，但款式字典无法组合成正式标准款式。

### 面料 ambiguous

29 条面料多候选主要来自 shadow 面料匹配口径过粗：候选常只按面料品类、密度、成分过滤，没有继续使用源文本中的纱支、组织、花型、颜色等信息。部分情况也暴露出字典中同一粗粒度组件对应多个标准面料行，需要后续主键、优先级或业务确认。

### 面料 conflict

2 条面料 conflict 均来自同一文本模式：`60% cotton 40% polyester, 4mm sateen stripe, white T250`。正式值为 `缎条/T250/C60/T40`，shadow 误把 `sateen` 优先解释为 `贡缎`，未让 `stripe/缎条` 优先，因此判断为 shadow_parser_wrong，Python 正式值更可信。
