# 本地项目最终删除计划

## 目标

在 GitHub 源码归档和核心业务资料加密备份均通过恢复验证后，将本地项目目录和项目专属 AppData 移入 Windows 回收站。

## 实施计划

1. 复核加密包 SHA-256、备份目录内容和恢复脚本。
2. 使用已交付恢复口令实际解密，对 24 个恢复文件逐项核对路径、大小和 SHA-256，然后清理临时明文。
3. 复核本地 HEAD、`origin/master`、远端 `master` 和 GitHub API 一致。
4. 提交并推送本轮删除计划、开发日志和唯一 Gate 报告，形成删除前检查点。
5. 在项目目录外精确验证两个删除目标，确认不包含备份目录、GitHub 或冻结目录。
6. 将项目目录和项目专属 AppData 移入 Windows 回收站，不执行永久删除。
7. 确认两个原路径均不再存在且备份仍存在；冻结 `Day01` 边界在删除前已不存在，全程不创建、不修改该边界；使用临时闭环克隆将实际删除结果补记到 GitHub，然后清理临时克隆。

## 禁止范围

- 不删除或移动 `%USERPROFILE%\Documents\BeddingOrderParser-Backup`。
- 不删除、改写或归档 GitHub 远端。
- 不触碰项目边界外的冻结 `Day01` 目录。
- 不删除非项目专属的共享模型缓存、Python 安装、GitHub CLI 凭证或其他用户数据。
- 不使用永久删除；仅移入 Windows 回收站。

## 完成标准

- 加密备份成功恢复，24 个文件的路径、大小和 SHA-256 完全一致，无临时明文遗留。
- 删除前检查点已推送，GitHub `master` 与本地 HEAD 一致。
- 原项目目录和项目专属 AppData 原路径均不存在。
- 备份目录仍存在；删除前已不存在的 `Day01` 边界全程未创建、未修改。
- GitHub 的最终退役报告已记录删除结果，临时闭环克隆已清理。
